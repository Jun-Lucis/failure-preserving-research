# Experimental-handoff template

Use this template when a computational programme reaches a point where a decisive physical measurement is unavailable.

## 1. Scientific question

What physical distinction needs to be resolved?

## 2. Current computational result

Summarize:

- model;
- parameter range;
- numerical robustness;
- public-data comparisons already completed;
- retained negative alternatives.

## 3. Competing hypotheses

State at least two outcomes that the proposed experiment could discriminate.

## 4. Requested measurement

Specify:

- material / system;
- control variable;
- parameter range;
- geometry;
- temporal / spatial / angular resolution;
- observable;
- uncertainty target;
- calibration requirements if known.

## 5. Frozen prediction

State the prediction before the new experimental data are acquired.

## 6. Falsification rule

What result would count against the computational hypothesis?

## 7. Why existing public data are insufficient

Identify the missing condition, range, resolution, metadata, or control.

## 8. Requested expert review

List assumptions requiring domain-specific experimental judgment.

## 9. Data-return format

Specify the minimum machine-readable information needed for an independent comparison.

## 10. Claim boundary

State what the experiment would and would not establish.
